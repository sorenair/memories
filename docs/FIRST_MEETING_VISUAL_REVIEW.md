# Memory polish guide — all memories

Updated November 17, 2026. The First Meeting review has been expanded into the
[all-memory polish guide](MEMORY_POLISH_GUIDE.md). **Use that document for agent
assignments and implementation priorities.** This entry keeps earlier links valid.

The scope is now design, layout, aesthetics, effects and atmosphere across the
existing memories, while retaining their core elements and the memory void:

- Interiors and social settings use selected evocative components, lighting,
  sound and partial surface traces, with ivory space between meaningful groups.
- Nature can become richer through layered, varied planting and landscape detail,
  with clear paths, open views, porous boundaries and appropriate ecology.
- Per-memory work and shared-system work have separate ownership. The guide
  includes current-memory starting points, a delegation template, before/after
  expectations and acceptance criteria.
