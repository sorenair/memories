# Painterly museum pieces

These editor-previewable pieces fill the museum-specific gaps in the existing component library. They inherit **PainterlyStadiumPiece**'s batched generated mesh/material lifecycle, which uses First Meeting's **arcade_geometry.gd** builder and the same matte pigment/stepped-light language. The shared regeneration button is labeled **Regenerate scenery**.

- **painterly_museum_portico.tscn**: six fluted Ionic columns, simplified curled capitals, a broad entablature, triangular pediment, and shallow steps. **Stone Color** sets the stone pigment. The interior and building wings are omitted deliberately. Six column blockers preserve an open central route. Steps and landing share one extruded side profile; its beveled treads and one concave **StairRamp** collider use identical heights. Keep paving outside Z ±3.5 to avoid intersecting its surface.
- **painterly_marble_statue.tscn**: **Figure** chooses Athlete, Draped Figure, Bust, or Veiled Lady Study. Each includes a molded plinth, a quiet carved silhouette, and a single collision volume. **Marble Color** changes the pigment. The first three are original classical studies with elongated proportions, carved folds, and selectively incomplete limbs. The fourth interprets Monti’s flower-wreathed, veiled bust using an opaque folded surface; it has a shorter collision volume.
- **painterly_museum_highlight.tscn**: **Exhibit** selects Jade Mountain or Kii Tokugawa Armor. Both include pedestals and collision. The jade mass reuses **BoulderGeometry**, then adds a quiet carved pavilion, stream, trees, and scholars in the same pigment. The armor uses lacquer plates, muted lacing, a seated silhouette, and a split gold crest. Each entire exhibit remains one static mesh/material.
- **painterly_gallery_display.tscn**: **Display Type** selects a Painting Partition or Bench. A painting exposes **Artwork**, **Canvas Size**, and **Wall Color**. The incomplete wall, frame, and canvas share one mesh surface/material. Canvas UVs use the shared scenery shader's kind 8 artwork sampler; the other scenery kinds retain their existing rendering. Benches have simple collision and a clear underside.

Origins are ground level, with front along local +Z. Use native scene transforms for placement. Shape/material changes regenerate the component, and generated children remain internal. These props do not require per-frame script callbacks, real-time shadow maps, or animation players.

Use the existing crowd, paving, light-wash, platform, audio, and fragment components for the rest of a museum scene. See the [playable museum memory](../../../scenes/memories/art_museum/README.md) for the four-zone composition and artwork provenance.
