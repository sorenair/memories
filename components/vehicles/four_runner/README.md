# Gray 2018 Toyota 4Runner

Instance `painterly_four_runner.tscn` for the parked, painterly 2018-generation 4Runner exterior requested for the backpacking memory. Its root is ground level and its front is local +Z. Body Color defaults to gray; Accent/Trim colors, Roof Rack Enabled, Headlights Enabled, collision, shadows, distance and recall are editable.

The [backpacking component guide](../../scenery/camp/BACKPACKING.md) documents its geometry, placement anchors, material behavior and references. Run `tests/scenes/backpacking_test.tscn` with F6 to inspect it beside the orange tent, cooking stove and explorer. The car is scenic rather than drivable, with a closed interior and blank rear plate.
