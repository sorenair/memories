# Painterly bonsai

Instance `painterly_bonsai.tscn` at ground level. Choose Twisted Upright, Windswept
or Half Cascade, then tune height, spread, trunk curve and canopy fullness. The
pot, optional pedestal, seed and shared foliage/bark colors complete the display.

See the [conservatory component guide](../../scenery/conservatory/README.md#bonsai)
for proportions, collision, recall, budgets and preview/check commands.
