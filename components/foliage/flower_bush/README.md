# Flowering bushes

Instance `painterly_flower_bush.tscn` at ground level. It extends the existing bush
with three clustered flower treatments, count/size and a compact color mix.
Foliage palettes, wind and smooth explorer response are shared with the bush.

See the [conservatory component guide](../../scenery/conservatory/README.md#flower-bushes)
for controls, budgets and preview/check commands.
